# YouTube Video Manager (MongoDB + Python CLI App)

This is a command-line Python application that allows you to manage YouTube video records using MongoDB. You can list, add, update, and delete video entries.

## 🚀 Features

- 📃 List all videos
- ➕ Add new video (name + duration)
- 🔄 Update video details
- ❌ Delete a video by ID
- 📦 MongoDB Atlas integration

## 🛠️ Requirements

- Python 3.10+
- [MongoDB Atlas](https://www.mongodb.com/cloud/atlas)
- `pymongo` library
